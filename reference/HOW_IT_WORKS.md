# How It Works — Clippng.in

Welcome to the **Clippng.in** landing site repository! This single-page site is built with **React**, **Vite**, and **Tailwind CSS**. It is 100% static (no backend server required) and deploys directly to Netlify or Vercel.

---

## 1. Project Structure

- `/src/config/` — **Central Configuration & Synced Data**
  - `siteConfig.js`: Brand name (`Clippng.in`), logo path, colors (`accentColor`), fonts, hero copy, `sahir@clippng.in` email settings, official social links, and the **`effects`** configuration block (`lightfall`, `wakeSlider`, `magicBento`, `scrollStack`).
  - `channels.js`: Definitions and stat computation for the 4 channels in the **"Channels we've clipped for"** `<ScrollStack />` (`MCG`, `Pump Plug`, `pump.moments`, `clips onchain`), local banner/avatar paths in `/public/channels/`, and optional verified manual stat overrides (`{ totalViewsOverride, totalClipsOverride, overrideAsOf }`).
  - `sources.js`: Source accounts for the automatic clip sync script (`@MCG_live`, `@MCGlive`, `@mcglivestream`, `@pumpfunplug`, `@clipsonchain`, `@pump.moments`), plus `maxClips` (default 12) and `perPlatformCap`.
  - `pinned.js`: Hand-picked favorite clips that always appear first in the phone carousel in the exact order given.
  - `watchlist.js`: Individual clip URLs and verified view counts for platforms without public unauthenticated feeds (TikTok, Instagram, X).
  - `clips.generated.json`: **Auto-generated by `npm run sync`.** Contains the merged, deduplicated, ranked clips and metadata (`generatedAt`, `viewsAsOf`, counts, warnings).
  - `clips.js`: Manual fallback clip list used only if `clips.generated.json` is missing.
  - `clipData.js`: Helper that reads `clips.generated.json` (or `clips.js`), filters out empty TODO URLs, and dynamically computes all site totals.
  - `brands.js`: Section copy and re-export of `clippedChannels` from `channels.js`.
  - `earnings.js`: Creator-facing Earning Estimator rate table and region availability rules.
  - `faq.js`: Accordion Q&A items.
- `/src/components/effects/` — **React Bits Open-Source Visual Components**
  - `Lightfall.jsx` + `Lightfall.css`: WebGL2 falling light-streak background canvas.
  - `WakeSlider.jsx` + `WakeSlider.css`: Interactive spring-physics wave bar slider (powered by `motion`).
  - `MagicBento.jsx` + `MagicBento.css`: Responsive bento dashboard grid with cursor spotlight, border glow, and click wave effects.
  - `ScrollStack.jsx` + `ScrollStack.css`: Sticky window-scroll card stack that pins and scales cards as the user scrolls down the page.
- `/src/components/` — **UI Sections & Wrappers**
  - `LightfallBackground.jsx`: Lazy-loads `Lightfall.jsx` (`React.lazy` + `Suspense`), reads `--accent-color` at runtime, checks WebGL2 support, applies mobile performance settings (`dpr={1}`, `streakCount={1}`), and renders a static dark+orange radial glow fallback when WebGL2 is unavailable or disabled.
  - `Header.jsx`, `Hero.jsx` (`#home`), `Clips.jsx` (`#clips`), `Brands.jsx` (`#brands`), `Earnings.jsx` (`#earnings`), `FAQ.jsx` (`#faq`), `Contact.jsx` (`#contact`), `Footer.jsx`.
- `/public/channels/` — **Local Channel Artwork**
  - Stores optimized `.webp` channel banners and avatars (e.g. `mcg-banner.webp`, `mcg-avatar.webp`) so the site never hotlinks to third-party platform CDNs for channel cards.
- `/scripts/` — **Pre-Build Sync & Logo Processing**
  - `sync-clips.js`: Main sync script run by `npm run sync` (and automatically before `npm run build`).
  - `adapters/youtube.js`, `adapters/tiktok.js`, `adapters/instagram.js`, `adapters/x.js`, `adapters/apify.js`.
  - `process-logo.js`: Crops `public/CLIPNNGDOTIN_LOGO.jpg` into `logo.png` (transparent wordmark), `logo-trimmed.jpg`, favicons, and `og-image.png`.
- `/.github/workflows/sync-clips.yml` — **Scheduled Refresh**
  - Runs `npm run sync` daily on GitHub Actions and commits `src/config/clips.generated.json` if new clips or updated view counts are found.

## 2. How the 4 React Bits Components Are Controlled

All four visual components are configured from **`src/config/siteConfig.js` -> `effects`** and inherit the site's accent color (`siteConfig.accentColor` -> CSS variable `--accent-color`):

| Component | Where It Lives | Used In | Config Key in `src/config/siteConfig.js` |
| :--- | :--- | :--- | :--- |
| **`Lightfall`** | `src/components/effects/Lightfall.jsx` (+ `.css`), wrapped by `src/components/LightfallBackground.jsx` | `src/App.jsx` (`scope: "page"`) or `src/components/Hero.jsx` (`scope: "hero"`) | `siteConfig.effects.lightfall` (`enabled`, `scope`, `speed`, `streakCount`, `streakCountMobile`, `glow`, `backgroundGlow`, `headGlow`, `bloom`, `twinkle`, `mouseInteraction`, `holdToWarp: false`, `vignetteOpacity`) |
| **`WakeSlider`** | `src/components/effects/WakeSlider.jsx` (+ `.css`) | `src/components/Earnings.jsx` (both *"Average Views per Clip"* and *"Clips Posted per Month"* sliders) | `siteConfig.effects.wakeSlider` (`barsDesktop`, `barsMobile`, `height`, `restHeight`, `gap`, `trackColor`, `crestColor`, `sensitivity`, `reach`, `skew`, `glide`, `smoothing`) |
| **`MagicBento`** | `src/components/effects/MagicBento.jsx` (+ `.css`) | `src/components/Brands.jsx` (right-column real-data dashboard grid) | `siteConfig.effects.magicBento` (`theme`, `columns`, `rowHeight`, `gap`, `radius`, `enableBorderGlow`, `enableSpotlight`, `spotlightRadius`, `clickEffect`, `intro`, `textAutoHide`, `enableStars`, `enableTilt`, `enableMagnetism`, `disableAnimations`) |
| **`ScrollStack`** | `src/components/effects/ScrollStack.jsx` (+ `.css`) | `src/components/Brands.jsx` (*"Channels we've clipped for"* full-width photo cards) | `siteConfig.effects.scrollStack` (`stackPosition`, `itemDistance`, `itemStackDistanceDesktop`, `itemStackDistanceMobile`, `itemScale`, `baseScale`, `dimAmount`, `holdDistance`, `smoothScroll: false`, `snap`, `useWindowScroll`, `sortByViews`) + `src/config/channels.js` |

## 3. Clip Sync Architecture & Data Flow

Because visitors' browsers cannot fetch third-party social platforms directly (due to CORS and login walls), all clip fetching happens **before the build** via Node (`npm run sync`):

```
┌────────────────────────┐   ┌────────────────────────┐   ┌────────────────────────┐
│  src/config/pinned.js  │   │ src/config/watchlist.js│   │  src/config/sources.js │
│   (Hand-picked first)  │   │ (TikTok / IG / X URLs) │   │ (YouTube @MCG_live...) │
└───────────┬────────────┘   └───────────┬────────────┘   └───────────┬────────────┘
            │                            │                            │
            ▼                            ▼                            ▼
┌──────────────────────────────────────────────────────────────────────────────────┐
│                         scripts/adapters/* (Node.js)                             │
│  • YouTube Adapter: Public Atom XML feed + Shorts tab (+ optional Data API v3)   │
│  • TikTok / X / IG Adapters: Official public oEmbed endpoints + local cache      │
└────────────────────────────────────────┬─────────────────────────────────────────┘
                                         │
                                         ▼
┌──────────────────────────────────────────────────────────────────────────────────┐
│                           scripts/sync-clips.js                                  │
│  1. Skip any TODO placeholder with an empty `url: ""`                            │
│  2. Merge & order clips (First 6 YouTube Shorts, next 2 TikTok clips)            │
│  3. Deduplicate by canonical video ID                                            │
│  4. Preserve previous good data on network failure (never crashes build)         │
└────────────────────────────────────────┬─────────────────────────────────────────┘
                                         │
                                         ▼
┌──────────────────────────────────────────────────────────────────────────────────┐
│                       src/config/clips.generated.json                            │
└────────────────────────────────────────┬─────────────────────────────────────────┘
                                         │
                                         ▼
┌──────────────────────────────────────────────────────────────────────────────────┐
│        src/config/clipData.js & src/config/channels.js ──► React Components      │
│  • #home: Verified views on featured clips + featured clip & channel counts      │
│  • #clips: Stacked phone carousel, platform switcher, lazy-loaded active embed   │
│  • #brands (MagicBento): 3 KPI tiles, log-scale views BarChart, Top 4 clips      │
│  • #brands (ScrollStack): Per-channel grouped views & clip counts on photo cards │
└──────────────────────────────────────────────────────────────────────────────────┘
```

### Zero Hardcoded Stats Rule
Every metric displayed across `#home`, `#clips`, and `#brands` (total views on featured clips, number of clips featured, platform breakdown, bar chart, top 4 clips, and per-channel totals in `ScrollStack`) is computed dynamically at render time from `clips.generated.json`.
